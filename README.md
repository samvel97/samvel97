### Hi, I'm Samvel 👋

I am a frontend engineer with 5+ years of production experience in React and TypeScript, most recently as Frontend Team Lead at PandaTech (Yerevan, Armenia). I led a team of three engineers, owned frontend architecture and CI, and reviewed code daily.

I build complex interfaces: an in-house SVG/Canvas seat-mapping platform, real-time chat on SignalR, and large data tables. I also led React 18→19 and Tailwind 3→4 migrations and published an open-source npm library, beautiful-react-table.

I use AI tools in my daily development and know where AI-generated code typically fails: edge cases, state bugs, accessibility and performance. I want to apply this to evaluating and improving AI coding models.
